# AI Instructions: Development Workflow & Tools

## Development Environment Setup

### Prerequisites

**Required Software**:
- Node.js 18+ (LTS recommended)
- npm or yarn
- Docker and Docker Compose
- Git

**Recommended Tools**:
- VS Code or similar IDE
- React Developer Tools (browser extension)
- Redux DevTools (for Zustand DevTools)
- REST Client extension (for testing APIs)
- Playwright Test for VS Code extension

### Initial Setup

```bash
# Clone repository
git clone <repository-url>
cd axiomancer-2.0

# Install backend dependencies
cd axiomancer-backend
npm install

# Install frontend dependencies
cd ../axiomancer-frontend
npm install

# Return to root
cd ..
```

### Environment Variables

#### Backend `.env` (axiomancer-backend/.env)

```bash
# Development
NODE_ENV=development
PORT=3001

# JWT
JWT_SECRET=your-super-secret-jwt-key-change-in-production

# Database (optional - omit to use SQLite)
# DB_HOST=localhost
# DB_PORT=5432
# DB_NAME=axiomancer
# DB_USER=axiomancer
# DB_PASSWORD=changeme123
```

#### Frontend `.env` (axiomancer-frontend/.env)

```bash
VITE_API_URL=http://localhost:3001
```

## Development Workflows

### Local Development (Without Docker)

**Terminal 1 - Backend**:
```bash
cd axiomancer-backend
npm run dev

# Server runs on http://localhost:3001
# Nodemon auto-restarts on file changes
```

**Terminal 2 - Frontend**:
```bash
cd axiomancer-frontend
npm run dev

# Vite dev server runs on http://localhost:5173
# Hot module replacement (HMR) enabled
```

**Terminal 3 - Database** (if using PostgreSQL):
```bash
docker run -d \
  --name axiomancer-db \
  -e POSTGRES_DB=axiomancer \
  -e POSTGRES_USER=axiomancer \
  -e POSTGRES_PASSWORD=changeme123 \
  -p 5432:5432 \
  postgres:16-alpine
```

### Docker Development

**Start all services**:
```bash
docker-compose up -d

# Services:
# - Backend: http://localhost:3001
# - Frontend: http://localhost:80
# - Database: localhost:5432
```

**View logs**:
```bash
# All services
docker-compose logs -f

# Specific service
docker-compose logs -f backend
docker-compose logs -f frontend
docker-compose logs -f database
```

**Rebuild after code changes**:
```bash
docker-compose up -d --build
```

**Stop services**:
```bash
docker-compose down

# Remove volumes too (deletes database data)
docker-compose down -v
```

## Database Workflows

### Database Management Scripts

**Clear Database**:
```bash
cd axiomancer-backend

# With confirmation prompt
npm run db:clear

# Force clear (no confirmation)
npm run db:clear:force
```

**What gets cleared**:
- All users deleted
- All character_states deleted
- Tables remain (not dropped)

### Database Inspection

**SQLite** (local development):
```bash
# Open database
sqlite3 axiomancer-backend/database.sqlite

# List tables
.tables

# View schema
.schema users
.schema character_states

# Query data
SELECT * FROM users;
SELECT * FROM character_states;

# Exit
.quit
```

**PostgreSQL** (Docker):
```bash
# Connect to database container
docker exec -it axiomancer-db psql -U axiomancer -d axiomancer

# List tables
\dt

# Describe table
\d users
\d character_states

# Query data
SELECT * FROM users;
SELECT user_id, current_location FROM character_states;

# Exit
\q
```

### Database Migrations

**Note**: No formal migration system currently implemented.

**Manual Migration Process**:
1. Update `DatabaseService.initialize()` with new schema
2. Add logic to handle existing data
3. Test locally with SQLite first
4. Test in Docker with PostgreSQL
5. Document changes

**Example Migration**:
```typescript
// In database.service.ts initialize()

// Add new column
await db.run(`
  ALTER TABLE character_states 
  ADD COLUMN new_field TEXT DEFAULT ''
`);

// Or create new table
await db.run(`
  CREATE TABLE IF NOT EXISTS new_table (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    data TEXT NOT NULL
  )
`);
```

## Git Workflows

### Branch Strategy

**Main Branches**:
- `main` or `master`: Production-ready code
- `develop`: Integration branch for features

**Feature Branches**:
```bash
# Create feature branch
git checkout -b feature/skill-system

# Work on feature...
git add .
git commit -m "feat(skills): implement skill learning system"

# Push to remote
git push origin feature/skill-system

# Create pull request on GitHub/GitLab
```

**Bug Fix Branches**:
```bash
git checkout -b fix/character-save-bug
# Fix bug...
git commit -m "fix(character): prevent negative HP"
git push origin fix/character-save-bug
```

**Current Branch** (from git status):
```
cursor/research-and-document-ai-workspace-improvements-7df0
```

### Commit Workflow

**Before committing**:
```bash
# Check what changed
git status

# Review changes
git diff

# Stage files
git add src/components/CharacterScreen.tsx

# Or stage all
git add .

# Commit with message
git commit -m "feat(character): add stat point allocation UI"

# Push
git push
```

**Commit Message Format** (see `.ai.code-standards.instructions.md`):
```
<type>(<scope>): <subject>

<body>

<footer>
```

### Pull Request Workflow

1. **Create PR** on GitHub/GitLab
2. **Fill out PR template** (if exists)
3. **Request reviewers**
4. **Ensure CI passes** (linting, tests, build)
5. **Address review comments**
6. **Merge when approved**

**PR Checklist**:
- [ ] All tests pass
- [ ] Linting passes
- [ ] TypeScript compiles
- [ ] No console errors
- [ ] Documentation updated
- [ ] Changelog updated (if applicable)

```bash
  plugins: [
    react(),
    visualizer({ open: true })
  ]
```

### Backend Performance

**Response Time Logging**:
```typescript
// Middleware to log request duration
app.use((req, res, next) => {
  const start = Date.now();
  res.on('finish', () => {
    const duration = Date.now() - start;
    console.log(`${req.method} ${req.path} - ${duration}ms`);
  });
  next();
});
```

**Database Query Performance**:
```typescript
// Log slow queries
const start = Date.now();
const result = await db.query(sql);
const duration = Date.now() - start;
if (duration > 100) {
  console.warn(`Slow query (${duration}ms):`, sql);
}
```

## Continuous Integration (CI)

**Typical CI Pipeline**:
```yaml
# .github/workflows/ci.yml (example)
name: CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2

      - name: Install Frontend Dependencies

      - name: Lint Frontend

        run: cd axiomancer-frontend && npm run build
      
      - name: Run Tests
        run: cd axiomancer-frontend && npm test
```

## Troubleshooting Common Issues

### Frontend Issues

**"Module not found" error**:
```bash
# Clear node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

**"Port already in use"**:
```bash
# Find process using port 5173
lsof -i :5173

# Kill process
kill -9 <PID>
```

**Stale cache**:
```bash
# Clear Vite cache
rm -rf node_modules/.vite
```

### Backend Issues

**Database connection error**:
```bash
# Check PostgreSQL is running
docker ps | grep postgres

# Restart database
docker restart axiomancer-db

# Check connection settings in .env
```

**Port already in use**:
```bash
# Find process using port 3001
lsof -i :3001

# Kill process
kill -9 <PID>
```

### Docker Issues

**Containers won't start**:
```bash
# Check logs
docker-compose logs

# Rebuild images
docker-compose build --no-cache

# Remove old volumes
docker-compose down -v
docker-compose up -d
```

**"Permission denied" errors**:
```bash
# Fix file permissions
sudo chown -R $USER:$USER .
```
