## What is Axiomancer-2.0?

Axiomancer-2.0 is a **philosophical role-playing game** where players learn and use **logical fallacies** as combat abilities and progression mechanics. The game combines traditional RPG elements with educational content about critical thinking and logical reasoning.

**Tech Stack**:
- **Backend**: Node.js + Express + TypeScript + PostgreSQL/SQLite
- **Frontend**: React + TypeScript + Zustand + Emotion
- **DevOps**: Docker + Docker Compose

## Project Philosophy

From the project lead (in `TODO.md`):

> "TJ ... Keep it slow dude!. I need to clean up SO much because you got eager and got a
> Game working, barely, but left a shitload of useless/uncalled values and tons
> of types filled with values.
> 
> Keep it slow!"

### Key Principles:

1. **Quality over Speed** 🐢
   - Write clean, maintainable code
   - Don't rush to "working" state
   - Refactor before adding features

2. **Remove Unused Code** 🧹
   - Delete dead code immediately
   - Don't leave commented-out code
   - Remove unused types and values

3. **Wait for Documentation** 📚
   - Don't implement features ahead of design docs
   - Skill system is blocked until documented
   - Consult game design docs before coding

4. **Explicit Types** 🔍
   - "Very Explicit types with Typescript"
   - No `any` types
   - All parameters and returns typed
   - Interface for every data structure

5. **Follow Conventions** 📏
   - Adhere to project standards
   - Consistent naming and structure
   - ESLint and Prettier configured
