# AI Instructions: Axiomancer Game Mechanics & Design

## Game Concept Overview

Axiomancer is a philosophical RPG where **logical fallacies are the core mechanic**. Players learn, master, and deploy fallacies as combat abilities, exploration tools, and character progression paths.

### Philosophical Foundation

The game is built around three **Philosophical Aspects**:
1. **Physical** - Represents physical prowess, material arguments, tangible effects
2. **Mind** - Represents mental acuity, rational arguments, intellectual effects
3. **Ailment** - Represents corruption, deception, manipulation, ailment/debuff effects

Each aspect has associated:
- Base stats (3 stats per aspect)
- Derived combat stats (Attack and Defense)
- Skills/fallacies that align with that aspect
- Equipment that enhances that aspect

## Character System

### Base Stats Structure

**Physical Aspect**:
- `strength`: Raw physical power, affects physical damage
- `endurance`: Stamina and resilience, affects HP and physical defense
- `agility`: Speed and reflexes, affects turn order and evasion

**Mind Aspect**:
- `intelligence`: Mental capacity, affects mind damage and MP
- `wisdom`: Judgment and insight, affects mind defense and MP regeneration
- `charisma`: Force of personality, affects persuasion and dialogue options

**Ailment Aspect**:
- `luck`: Fortune and chance, affects critical hits and drops
- `will`: Mental fortitude, affects ailment resistance
- `perception`: Awareness and insight, affects ailment accuracy

### Derived Stats (Calculated from Base Stats)

**Combat Stats**:
- `physicalAttack`: Calculated from strength + agility
- `physicalDefense`: Calculated from endurance + agility
- `mindAttack`: Calculated from intelligence + charisma
- `mindDefense`: Calculated from wisdom + will
- `ailmentAttack`: Calculated from luck + perception
- `ailmentDefense`: Calculated from will + perception

**Resource Stats**:
- `maxHP`: Hit Points, calculated from endurance + level
- `currentHP`: Current health
- `maxMP`: Mana/Mind Points, calculated from intelligence + wisdom
- `currentMP`: Current mental energy

**Progression Stats**:
- `level`: Character level (starts at 1)
- `experience`: XP points earned
- `unassignedStatPoints`: Stat points available to spend

### Stat Point System

**Character Creation**:
- Players receive a budget of stat points (e.g., 30 points)
- Must distribute across all 9 base stats
- Minimum 1 point per stat (typically)
- Can save points for later if desired (stored in `unassignedStatPoints`)

**Leveling Up**:
- Gain experience from defeating enemies
- Threshold: 1000 XP = 1 level up
- XP resets to 0 after leveling
- Gain 5 `unassignedStatPoints` per level
- Players assign points manually via Character Screen

**Stat Assignment Rules**:
- Can only increase stats one point at a time
- Must have unassigned points available
- Changes immediately affect derived stats
- Auto-saves after modification

**Character Appearance**:

- Portrait selected from gender-appropriate images
- Located in `public/portraits/`

## Combat System

### Combat Initiation

**Trigger**:
- Player clicks on combat node on map
- Random enemy selected for that location
- `gameStore.startCombat(enemyId)` called

**Combat State Initialization**:
```typescript
{
  enemy: Enemy,              // Enemy data
  playerTurn: boolean,       // Whose turn is it?
  turnNumber: number,        // Combat round counter
  combatLog: BattleLogEntry[], // History of combat actions
  playerBuffs: BuffDebuff[], // Active player buffs
  playerDebuffs: BuffDebuff[], // Active player debuffs
  enemyBuffs: BuffDebuff[],  // Active enemy buffs
  enemyDebuffs: BuffDebuff[] // Active enemy debuffs
}
```

### Combat Flow

**Turn-Based System**:
```
1. Combat begins (player usually goes first based on agility)
2. PLAYER TURN:
   - Select action: Attack, Skill, Item, Flee
   - Resolve action
   - Update combat log
   - Check for victory
3. ENEMY TURN:
   - AI selects action
   - Resolve action
   - Update combat log
   - Check for defeat
4. Process buffs/debuffs (duration ticks, effects apply)
5. Increment turn number
6. Repeat from step 2 until victory or defeat
```

### Combat Actions

**1. Basic Attack**:
- Uses `physicalAttack` stat
- Calculates damage against enemy `physicalDefense`
- No MP cost
- No special effects

**2. Skills/Fallacies**:
- Uses equipped skills from `character.equippedSkills`
- Organized by philosophical aspect (physical, mind, ailment)
- May cost MP
- May have special effects (damage, buffs, debuffs, status ailments)

**3. Items**:
- Use consumable items from inventory
- Effects: heal HP, restore MP, remove debuffs, etc.
- Consumes item from inventory

**4. Flee**:
- Attempt to escape combat
- Success chance based on agility vs enemy speed
- Failure wastes turn

### Damage Calculation

**Basic Formula**:
```
Damage = (AttackerStat - DefenderStat) * Modifier + Random(0, 5)
If Damage < 0: Damage = 1 (minimum damage)
```

**Attack Types**:
- **Physical Attack**: `physicalAttack` vs `physicalDefense`
- **Mind Attack**: `mindAttack` vs `mindDefense`
- **Ailment Attack**: `ailmentAttack` vs `ailmentDefense`

**Modifiers**:
- Critical hit chance based on `luck`
- Buffs/debuffs modify attacker/defender stats
- Elemental weaknesses (if implemented)

### Skill Learning

**How Skills Are Acquired**:
1. **Story Progression**: Unlock skills by completing story events
2. **Level Requirements**: Some skills require minimum level
3. **Stat Requirements**: Some skills require minimum stat values
4. **Prerequisite Skills**: Some skills require learning others first
5. **Trainers/NPCs**: Learn from NPCs in the world

**Learning Check**:
```typescript
canLearnSkill(skill: Skill): boolean {
  // Check level requirement
  if (character.level < skill.levelRequirement) return false;
  
  // Check stat requirements
  for (const [stat, value] of Object.entries(skill.statRequirements)) {
    if (character.baseStats[stat] < value) return false;
  }
  
  // Check prerequisites
  for (const prereqId of skill.prerequisiteSkills) {
    if (!character.availableSkills.find(s => s.id === prereqId)) {
      return false;
    }
  }
  
  return true;
}
```

**Equipped Skill System**:

```typescript
  locationUnlock?: string;
```

### Quest Flow

**Quest Acceptance**:
```
1. Player talks to NPC (quest giver)
2. Dialogue shows quest details
3. Player accepts quest
4. gameStore.addQuest(quest) called
5. Quest appears in Quest Log
```

**Quest Progression**:
```
1. Player performs actions (kill enemy, collect item, etc.)
2. Game checks if action contributes to active quest objectives
3. If yes: Increment objective.current
4. If objective.current >= objective.required: Mark objective as completed
5. If all objectives completed: Enable quest turn-in
```

**Quest Completion**:
```
1. Player returns to quest giver (or completes final objective)
2. gameStore.completeQuest(questId) called
3. Quest status = 'completed'
4. Rewards granted:
   - Experience added
   - Items added to inventory
   - Skills unlocked
   - New locations/nodes unlocked
5. Check for new quests unlocked by prerequisites
```

## Save System

### What Gets Saved

**Full Game State**:
- Complete character object (stats, skills, inventory, equipment)
- Current location and node
- Story flags and choices
- Quest log (active and completed quests)
- Locations and which nodes are unlocked
- Map energy
- Game phase

### Save Format

Sent to backend as JSON:
```typescript
{
  character: { /* full character object */ },
  currentLocation: 'fishing_town',
  currentNode: 'home',
  story: { /* story flags */ },
  inventory: { /* items and gold */ },
  locations: { /* location states */ },
  questLog: [ /* quests */ ],
  mapEnergy: 8,
  maxMapEnergy: 10,
  gamePhase: 'exploration',
  savedAt: 1699564800000  // Unix timestamp
```

### Auto-Save Triggers

**Automatically saves after**:
- Character creation
- Stat point assignment
- Completing a quest
- Defeating an enemy
- Equipping/unequipping items
- Learning a skill
- Moving to a new location
- Completing a dialogue event

**Debounced**: 500ms delay to batch rapid changes

## Game Balance Considerations

### Stat Scaling
- Ensure derived stats scale appropriately with base stats
- Balance physical/mind/ailment to all be viable paths
- Prevent any single stat from being "dump stat"

### Combat Difficulty
- Early enemies: 20-50 HP, low stats
- Mid enemies: 100-200 HP, moderate stats
- Late enemies: 300-500 HP, high stats
- Bosses: 1000+ HP, very high stats

### Experience Curve
- 1000 XP per level keeps it simple
- Enemy XP rewards should scale with difficulty
- Typical enemy: 100-200 XP
- Boss enemy: 500-1000 XP

### MP Costs for Skills
- Basic skills: 5-10 MP
- Intermediate skills: 15-25 MP
- Advanced skills: 30-50 MP
- Ultimate skills: 75-100 MP

### Equipment Progression
- Starter equipment: +1 to +3 stats
- Mid-tier equipment: +5 to +10 stats
- End-game equipment: +15 to +25 stats
- Legendary equipment: +30+ stats, special effects
